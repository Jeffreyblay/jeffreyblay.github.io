What it does

Everything you need.
Nothing you don't.

Built specifically for retain log book management — no bloat, no complexity.

📋
Full record management
Add, edit, view and delete log records. Every field from your existing CSV is supported out of the box.
🔍
Search & filter
Instantly search by file number, sample number, shore tank, tech initials or cabinet. Filter by status or condition.
⚠️
Due date tracking
Records are automatically flagged as Active, Due Soon or Overdue. The dashboard surfaces anything needing attention.
📧
Email notifications
Automated daily alerts at 08:00 for any records that are due soon or overdue. Configure once, runs automatically.
⇪
CSV import
Upload your existing spreadsheet and the system auto-maps your column headers. Matching records are updated, new ones are added.
🏢
Office network ready
Runs on one PC, accessible by your whole team from any browser on the same WiFi. No internet or cloud accounts needed.
Setup

Up and running
in 4 steps.

No server knowledge required. If you can install an app and open a browser, you can run ComplianceLog.

01
Download & unzip
Download the zip and extract it to C:\ComplianceLog\ on the PC that will host it.
02
Install Python
Download Python from python.org and install it — tick "Add Python to PATH" on the first screen.
03
Double-click start.bat
Run start.bat to launch the app. The first run installs dependencies automatically — takes about a minute.
04
Import your CSV
Open your browser, go to localhost:5000, click Import CSV and upload your existing log file. Done.
Data structure

Matched to your
existing log format.

Every field from your CSV is supported. Import your existing data without changing anything.

01
Sample Date
The date the sample was taken or logged.
02
File Number
Unique file identifier for each log entry.
03
Sample Number
Sample reference number within the file.
04
Shore Tank
The shore tank associated with this sample.
05
Level
Recorded level measurement for the sample.
06
Movement
Movement description or classification.
07
Condition
Current condition or state of the record (e.g. active, dgr).
08
Cabinet & Shelf Number
Physical storage location for the physical file.
09
Due Date
The date this record is due for review or action. Drives the status system.
10
Tech Initials
Initials of the technician responsible for this record.
